# Guia da documentação

A documentação do nextOrganize está dividida em dois escopos:

| Escopo | Para quem | O que tem |
| --- | --- | --- |
| [Funcional](funcional/README.md) | Quem usa o app ou decide o que ele faz | Funcionalidades, telas, regras de atraso, hábitos, desempenho e tipos, sem detalhes de código |
| [Técnico](tecnico/README.md) | Quem programa, testa ou publica | Execução, arquitetura, ambientes, Supabase, ferramentas, API e banco de cada domínio |

O [histórico](historico.md) fica fora dos dois: registra as mudanças por data, o
que mudou para quem usa e por dentro, e o que está planejado.
